# 用户控制台信息架构

更新时间：2026-10-10。以 docs/18、19、20 与最新用户决定为准；实现证据见 docs/21。

## 用户任务

主要入口为 API Key、模型、用量与请求、余额与套餐、邀请与收益、设置。API Key 为首页与独立一级入口；网页试用和媒体为辅助工具。未完成的团队、应用、成员和 Webhook 不在导航中展示。

创建 Key 直接配置所有/指定模型、累计 USD 消耗上限、有效期；RPM/并发折叠为高级项。无需先充值、选工具或完成验证。模型详情提供 Agent 配置和调用协议，采用品牌实际地址与公开模型 ID，不接受提供商、路由、灰度等内部控制。

## 邀请与收益

每位用户拥有专属邀请码与链接，在同一账户查看人数、赠送积分、分佣资格方法与进度、个人推广佣金与结算。达线不产生新账户或另一套使用流程；专业推广范围按已有服务端权限提供。旧 partner 地址迁至对应收益标签，普通用户登录进入 /app，管理岗位仍按有权工作区。

## 状态与上下文

URL 保留 Key ID、模型、说明标签及合法返回目标，不保存 Key 秘密。Key 可编辑限制，轮换不重置净消耗。限额按账务事实原子预留、结算、释放与冲正，未知请求保留占用。

用量内区分汇总、请求与账单核对；钱包区分消费额度、套餐权益、订单与流水。佣金与消费额度分开；充值不计佣。加载失败不显示零，提交结果未知使用原操作回查。

2026-10-10补充：Key显示真实累计用量与剩余额度，实际结算可超过设置上限；账户负余额原样显示并引导充值补齐。新请求按适用余额和Key限额的合理预估原子准入，既有请求不会因到期、停用或事后超额丢失实际费用。
