# TokenHub 飞书产品需求目录

状态：已锁定（2026-08-30）
用途：飞书多维表格「需求」表的产品目录。Wiki 模块文档与 Base 行都以本清单为准。
关联：`docs/01`、`docs/08`、`docs/09`

## 1. 管理约定

- **工作索引**是飞书多维表格，不是 GitHub Issue、飞书任务或群消息。
- **大模块**是需求表上的单选字段「模块」。选项锁死，成员不能在格子里新增模块名；增删选项只能园丁走 evolution。
- **需求点**是需求表的一行。能力级粒度：可独立写出 3–5 条验收。
- **Wiki** 每个模块一篇说明；需求行的「文档」字段链到对应模块文档。技术选型单独一篇 [技术栈](https://hcn928rez9ty.feishu.cn/wiki/KF6pw8QXqiQfSYkWiovcRWulnnt)，不写进需求模块页。
- 沙箱已合入、等人验收 → 状态 **待验收**。尚未开工（含生产接入、P1/P2）→ **待处理**（口语里的「未开始」）。**完成**只能人点。
- 常驻需求「团队运转」不选模块。
- 明确不做的能力、以及企业级后续能力，当前都不建需求行。前者永不做；后者等有真实企业客户再立项。

## 3. 不建需求

当前目录不建行，分两类。

**明确不做**

- 无限级代理树
- 第一版自动对外提现 / 打款
- 复杂 CRM、工单、合同、发票系统
- 多推广来源拆分归因
- 用实时毛利润替代可解释的消耗计佣
- 渠道商自带上游 Provider Key（渠道 BYOK）；上游凭据只由平台维护

**企业级（有真实企业客户再立项）**

- 提供商数据策略、ZDR、按区域过滤路由

## 4. 需求点

标题用于飞书「标题」字段。验收摘要抄进「验收摘要」。

### 4.1 身份与渠道

| 标题 | 状态 | 验收摘要 |
|---|---|---|
| 邮箱密码注册登录 | 待验收 | 邮箱密码可注册登录；未授权 API 返回 403 |
| A/B/C/OEM 渠道与数据隔离 | 待验收 | 用户归属一个渠道；渠道管理员只能看本渠道；用户自助改渠道 403 |
| 唯一归因、推广码与人工改归属 | 待验收 | 注册时绑定唯一推广来源；OAuth 暂存推广码；管理员改归因写审计 |
| 四类入口与 OEM 品牌配置 | 待验收 | 公共站/用户/渠道/管理按域名与角色渲染；OEM 可配 Logo、配色、域名 |
| 用户封禁与解封 | 待验收 | 封禁后登录/会话/API Key 403；未结算佣金 held；需二次确认 |
| 管理角色隔离 | 待验收 | 财务不能看 Provider/轮换凭据；审计不能退款；技术值班不能退款 |
| 管理员 TOTP | 待验收 | 可绑定/启用/关闭；启用后敏感操作可要求 TOTP；关闭需确认 |
| 真实 Google OAuth | 待处理 | 真实 Google code 可换 token/profile；不再走 MockGoogleExchange |
| 公网 OEM HTTPS | 待处理 | OEM 域名 CNAME 到 Cloudflare 入口；平台登记 Custom Hostname 后由 Cloudflare 签发续期；未登记域名 tls-check 拒绝；.localhost 仍走沙箱，不自建公网 Let's Encrypt |

### 4.2 模型与 Provider

| 标题 | 状态 | 验收摘要 |
|---|---|---|
| Provider、凭据与健康检查 | 待验收 | 凭据密文存储、列表只显示指纹；健康探测不会计费；401/429/5xx 按规则摘除 |
| 公开模型目录、映射与价格版本 | 待验收 | 同步结果先 draft，审核后发布；改价不改旧账单；弃用不删历史 |
| 上游账号池 | 待验收 | 一个 Provider 多 Key；冷却/失效可跳过；池内无可用账号则跳过该 Provider |
| 渠道模型白名单 | 待验收 | 平台从目录授权给租户；租户不能自建提供商或模型；用户 Key 可再收窄 |
| 手工创建、挂载与弃用模型 | 待验收 | 手工创建默认 draft；attach 不破坏历史映射；deprecate 保留价格版本 |
| 真实 Gemini 上游 | 待处理 | 配置 Base URL 后可真实调用 Gemini，不再回声或固定 unavailable |
| 复合模型组与模型别名 | 待处理 | 一个对外 ID 可映射多模型组合；别名不影响历史账单 |

### 4.5 钱包与账务

| 标题 | 状态 | 验收摘要 |
|---|---|---|
| 用户钱包与请求预授权 | 待验收 | 请求前 Reserve；不足 402 且不调上游；并发不双扣 |
| usage 结算、释放与幂等 | 待验收 | 按价格快照结算；重复 usage 不重复扣款 |
| 缺 usage 进入待对账 | 待验收 | 无 usage 不按估算扣款；进入 pending_reconciliation |
| 价格快照与客户账单 | 待验收 | 历史账单金额不随后续改价变化；可按 request_id 重算 |

| 套餐创建、校验、审核与下架 | 待验收 | 低于底线或高风险进审核；平台可下架；不改历史订单 |
