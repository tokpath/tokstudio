# 员工与权限

平台与 OEM 都在运营组提供同一套员工管理界面。客户、渠道管理员交接和公司内部员工各有独立入口。

- 平台岗位：管理员、运营、财务、技术、只读审计。
- OEM 岗位：管理员、运营、财务、只读审计。采用独立角色代码，管理范围只限所属 OEM 及其直属 渠道。
- 可新建员工账号，或按邮箱加入已注册的公司本部账号；不迁移客户渠道归属，不接收其他公司的员工。
- 可叠加岗位，岗位权限取并集。只有公司管理员可分配权限、停用或恢复员工。
- 停用员工阻止登录并撤销旧会话和 API Key；恢复后重新登录。岗位变更对现有会话立即生效。
- 禁止修改自身权限、停用自身、移除最后一个有效管理员。按公司串行化权限变更，并在事务内复核操作人资格。
- 所有员工操作与审计记录同事务落库，记录操作人、时间、前后权限；密码不进入日志。
- 已有管理员纳入员工列表；开发环境种子不覆盖人工修改或重新启用停用账号。
- OEM 岗位经明确的接口策略授权，禁止平台目录、全局账务、基础设施及下级 OEM 权限。
