# 用户控制台信息架构

状态：**已拍板，工程随本 PR 落地**  
日期：2026-09-05  
对照：`DESIGN.md` §4.3 / §4.5 / §4.9、`docs/01` 用户控制台范围、`docs/13` 管理面约定（一页一事、宽表钉列、短表单 Dialog）。  
本文件与旧实现冲突时，**以本文件为准**。

## 1. 目标

用户台首页曾把余额、套餐、Key、示例、用量、媒体、设置整页堆叠，总览失去「一眼看自己」的作用。重新划清：

- **总览**放个人状态统计 + 个人用量趋势（图）+ 快捷入口；
- 每个侧栏路由一页一事；
- 列表 / 表单交互对齐管理台约定（宽表钉首末列；短表单 Dialog；多区块留在独立页）。

## 2. 侧栏结构（保持现有分组，职责写清）

| 分组 | 路由 | 一页一事 |
|------|------|----------|
| 开始 | `/app` | 个人状态 + 用量趋势图 + 快捷跳转 |
| 开始 | `/app/playground` | 快速试用（走同一网关） |
| 开始 | `/app/keys` | API Key 列表；创建用 Dialog |
| 开始 | `/app/catalog` | 可调用模型价目 |
| 账本 | `/app/wallet` | 余额 / 充值 / 现金流水 |
| 账本 | `/app/plans` | 套餐与权益 |
| 账本 | `/app/usage` | 用量**汇总**：指标、趋势、按 Key 汇总 |
| 账本 | `/app/reconciliation` | **对账**：三桶（余额 / 冻结 / 可提现）与同一窗口 usage；匹配绿色；差异只送入 `pending_reconciliation`，无估扣 |
| 账本 | `/app/activity` | 请求**明细**（网关回单：请求结果 / 计费状态 / 费用 / 失败原因） |
| 账本 | `/app/media` | 媒体任务**列表优先**；顶栏筛选 / 刷新 / 新建；创建表单进 Dialog |
| 用户 | `/app/referral` | 推荐计划 |
| 更多 | `/app/docs` | 接入示例（Key 占位） |
| 更多 | `/app/settings/*` | 账户 / 团队 / 成员 / 开票 / 配额 / 应用 / Webhook |

边界（不变）：

- 不出现 Provider 密钥、平台成本、他人数据、分销佣金；
- 渠道归属注册时写死，设置页不提供「切换渠道」。

## 3. 总览 `/app`

对照公开产品仪表盘（如 tokpath.com/dashboard）：一眼看状态与趋势，办事去子页。

只保留：

1. **个人状态统计**：可用余额、预授权占用、API Key 数量、最近一张路由回单（可点进对应页）。
2. **主操作**：创建 API Key、充值余额（跳到业务页，不在总览嵌表单）。
3. **个人用量趋势**：周期请求数 / Token / 花费摘要 + 按日趋势图 + 按模型分布（有真实事件才画图，不画假平滑线）；「查看用量汇总」链到 `/app/usage`。
4. **快捷入口**：余额、Key、试用、用量、请求明细、媒体、模型广场、文档。

禁止：

- 在总览嵌入完整 Wallet / Plans / Keys / Examples / Usage（筛选 + 按 Key 表）/ Media / Settings 面板；
- 促销墙、渠道切换、平台运营指标。

## 4. 页面约定（对齐管理台）

| 约定 | 用户台落地 |
|------|------------|
| 一页一事 | 用量 = 汇总；请求明细 = 逐条回单；互不重复堆完整明细表 |
| 宽表钉列 | 请求明细等 ≥3 列宽表用 `ScrollTable`，默认钉首列 + 末列 |
| 短表单 Dialog | API Key 创建、媒体新建（字段多也可进可滚动 Dialog）；总览不嵌创建表单 |
| 多区块留页 | 钱包充值留在 `/app/wallet`；媒体以列表为主，创建走 Dialog |
| 图表优先 | 总览先看趋势；`/app/usage` 再筛 Key/模型；usage↔三桶对账去 `/app/reconciliation`（无假图）；明细去 `/app/activity` |

## 5. 与旧实现的差异

| 旧 | 新 |
|----|----|
| `/app` 纵向堆 7 个业务面板 | 状态卡 + 趋势图 + 快捷入口 |
| 用量页同时含汇总与逐条明细 | 汇总在用量；逐条在请求明细 |
| 总览可当「万能工作台」 | 总览是仪表盘（含趋势），办事去子页 |

## 6. 实现边界

本 PR 落地文档 + 总览瘦身 + 用量/明细职责拆分 + 请求明细改 `ScrollTable`。渠道台总览仍偏「一页多面板」，不在本 PR 范围。
