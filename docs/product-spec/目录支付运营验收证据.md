# 目录、支付、采购与运营验收证据

本记录对应 `TokenHub关键业务案例与验收标准.md` 的 A014—A032、A090—A100、A104、A119—A130。代码以本次重构的新领域为准，无旧业务兼容层。日期：2026-10-16。

“真实外部联调”指独立运行在仓库外的 HTTP/RPC/SSE/SMTP 协议服务、PostgreSQL 与私有 MinIO，不代表已经使用真实供应商 Key、商户或银行资金验证。材料齐全后的真实账号验证仍是启用前条件。NOWPayments 的人工外部退款不冒充其自动退款 API；EVM 仅只读 RPC，禁止保存钱包私钥或发起转账。视频原生用量不能可靠确认时保持不可计费/待核实，不把请求参数当作真实用量。

## 已运行的隔离验证

- 六域此前同一轮实际 PostgreSQL、独立协议服务与 MinIO 的 `-p 1 -race` 全部通过：catalog 3.352s、modelruntime 1.992s、payments 2.802s、operations 6.037s、cooperation 24.249s、commerce 46.473s。其后新增必要修复采用针对性验证，最终全仓结果由主代理统一记录。
- 支付平台资产版本、历史网络/确认数快照、停用后实际 RPC 核查、退款 sealed 查询保护：实际 PostgreSQL + 独立 RPC `-race` 2.937s 通过。`TestRefundExecutionSealingNeverQueriesOrRetriesProvider` 检查网络前 durable query claim 与 seal 互斥，已封存执行不能重新请求外部退款。
- 采购稳定币八场景与销售 DB 业务时钟覆盖：`TestExternalStablecoinProcurementRefundAuthorizationAndActualCash`、`TestPostgresSaleCoverageSeesRightsEffectiveOnDatabaseClock`，实际 PG + Docker 18091，`-race` 15.014s 通过。银行 partial 9+1、正常原路与争议六场景此前通过 8.45s。
- 收款执行时估值最后专项：`TestReceiptValuationUsesActualTimeAndPreservesPendingOriginalMoney`、`TestNativeUSDReceiptNeedsNoFXOrInventedPaymentTime`、原子收款匹配失败恢复、NOW 外部原币付款→人工核实执行时估值→采购履约、实际财务报告。`-race`：payments 3.153s、cooperation 3.969s、operations 3.818s。
- 上述估值测试覆盖：下单价在实际付款时已过期不沿用；非 USD 缺实际付款时点不以观察时点替代；原币事实先持久、`awaiting_valuation` 无假 USD；财务精确权限/经营方/订单范围；同一事实并发确认仅一条不可变估值与一笔收款；匹配故障不丢已核实估值，`RunPendingFacts` 重放恢复；迟到重复回调不重新估值；USD 原币恒等且未知 `PaidAt` 保持未知。
- `PendingReceiptObligations`、`RecordedReceiptLinks` 与 commerce `UnsettledReceiptFunds` 形成实际责任链，closed 订单也保留原币及已记收款的未分配义务。收款/估值在事实锁前获取经营方责任 SHARE 锁，门户再解析历史受益客户或采购买方 SHARE，和关闭/接管 UPDATE 锁互斥。组织域的真实关闭/接管专项另行记录。
- 财务报告 `Payments` 单独返回待核实事实数量与按币种的原币金额，不虚构 USD；无估值原币、匹配待办与未知费用不作为确认 0。
- 主模型/支付独立 Docker 已在压测结束后重新构建至 HTTP 18090、SMTP 18027；退款 RPC 测试独立 Docker 18091、SMTP 18029 使用同一最新协议代码。所有服务位于 tokstudio 仓库外 integration-lab，未设为生产默认地址。最终回归模型用 18090、支付用 18091，避免控制面相互干扰。
- 新增迁移：operations `0002_invoice_policy_history.sql`；cooperation `0004_external_refund_destinations.sql`、`0005_refund_observations.sql`、`0006_refund_route_versions.sql`；payments `zz_refund_executions.sql`、`zz_refund_fact_bindings.sql`、`zz_supported_assets.sql`、`zz_refund_closures.sql`、`zzz_receipt_valuations.sql`、`zzzz_receipt_fact_recovery.sql`。原迁移文件不回写。正式注册由各包 Migrations() 自动提供；Schema() 仅用于新建隔离测试库完整安装。
