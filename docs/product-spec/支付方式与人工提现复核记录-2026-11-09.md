# 支付方式与人工提现复核记录（2026-11-09）

本次按用户确认修正支付方式的业务含义，保留统一设置页与一套费用规则。

- 现金并入系统内置的线下支付。平台、OEM、渠道都可直接启用，无技术接入步骤。
- 人工提现与线上收款分别配置、分别显示状态。新增方式不会自动开通提现。Stripe 仅收款，不映射为银行卡提现。
- 经营方能预览客户的收款资料。银行支行、PayPal 姓名等非必要资料可选；微信采用人工联系核实说明；USDT 按经营方开放网络验证地址。
- 提现先展示实际到账币种与金额；异币种须发布本方式的兑换比例。申请冻结报价、费用和资料，后续规则变化不重算，登记付款直接使用原约定金额。
- 链上收款的资产、网络、合约和精度来自平台版本，经营方不重复填写，USDT 入口不混入 USDC。
- 渠道页面不出现下级采购适用范围，佣金与余额页面保留申请办理入口，不恢复独立方式设置。
- 中、英、日、俄文案同步，生成的服务端语言文件和 OpenAPI 一并更新。

已有配置通过新版本调整：现金折叠到线下支付；旧银行卡配置归为 Stripe 收款；需要重新确认币种/网络的支付宝、微信、USDT 提现配置暂停，经营方补齐后启用。既有订单与提现事实、手续费快照不重写，无关账户资产不清除。
