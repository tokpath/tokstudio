## 1. 渠道组织

| 类型 | 含义 | 可建下属 |
| --- | --- | --- |
| A | 自营，等同平台 | B、C |
| B | 分销商 | 无 |
| C | OEM 贴牌，业务上视为另一个平台（技术依赖本平台） | 仅 B，不可再建模 C |

- A 和 C 各自经营一个品牌。C 与 A 是技术合作关系；A 只管理直属 B 和 C，C 管理自己的直属 B。B 无独立品牌，继承上级品牌，但保留独立后台并管理自己的用户。
- 同一品牌只使用一套终端套餐和售价：A 制定 A 品牌套餐，C 制定 C 品牌套餐；B 不创建、发布或下架套餐。套餐可适用于整个品牌或指定直属 B。平台与 OEM 各自发布和下架自己品牌的套餐。
- B 可管理本渠道用户、收款、推广、额度和已授权模型的本地上下架；上级平台可管理直属 B 的状态、管理员与模型授权。C 的下属 B 不出现在 A 的日常管理列表，A 不代 C 创建、停用或交接该 B。
- 全库只有一个 A。可以有多个 C；C 不能再建模 C（避免把品牌再转卖到第三国）。
- 每个 C 使用独立品牌；C 创建时须指定已创建且尚未分配给其他平台的品牌。B 创建时自动继承上级品牌；渠道类型和品牌归属创建后不在渠道详情更改。
- C 是不碰技术的商人：向 A 买进积分，换品牌/域名在母国经营；技术仍用本平台。
- B 无论挂在 A 还是 C 下，都有**自己的积分池**，对外都是分销商。A 下的 B 向平台买积分；C 下的 B 向该 C 买积分。
- C 及其下属 B 共用 **C 的**分佣比例与达线（C 相当于该市场的「平台」）；支付商户在各渠道组织自己身上（B 收 B 的用户的钱，与 A 下 B 相同）。
- C 不维护上游 Provider、密钥、模型目录、网关基建。

## 2. 推广

链：渠道 → 代理商 → 个人推广员（推广员可再发展推广员）。  
计佣只沿邀请链向上 **两跳**（直接、间接），避免多层法规风险。

- 代理商是独立角色，渠道后台可建，再发展个人推广员。
- 个人推广员：渠道台种子；终端用户达线后获得分佣资格。
- 注册即为每个用户生成专属推广码，并记录 **分佣资格**（默认无）。
- 无分佣资格时，分享只发赠送积分，不发佣金。
- 注册未带他人推广码：不发佣金。
- 无间接推广者：只发直接（例如渠道直属推广员）。

## 3. 分佣

三个可配比例：总佣金、直接、间接。直接+间接不得超过总。  
A、B 共用平台一套；C 自改（作用于 C 及其下属 B）。  
基数：已确认 API 消耗（批发价），充值不计佣。  
所得进入用户 **现金钱包（佣金钱包）**，不用于抵扣 API。  
冻结期后解冻；P0 仍可人工结算打款。

## 4. 积分与钱包

金额:积分 = 1:1。渠道先充值换成积分；用户充值 = 从所属积分池划转（渠道可用减少、用户充值积分增加）。不必另立「库存」领域名。

用户消费顺序：**赠送积分 → 充值积分**。赠送积分不可退款。  
达线规则（累计消费 / 单笔充值、满多少）与赠送触发条件均可配置；A/B 在平台，C 自己配。

## 5. 渠道账户

流水为准，汇总可缓存。

- **充值汇总**（正）
- **未消费 / 已消费**：未消费为池内剩余充值积分；已消费 = 充值汇总 − 未消费
- **营销子账户**：不是预算，而是已产生支出，用 **负数**。内部分 **冻结**（佣金未解冻）与 **已发放**（已解冻佣金 + 即时积分奖励）。解冻只转档，总额不变。
- **供应商支出**（负）：线下已付款、线上只记账。A 记付给模型商；C 和挂 A 的 B 记付给平台；C 下的 B 记付给该 C。录入不填渠道，系统按操作者账本写入。

**盈亏** = 已消费 + 营销 + 供应商支出（后两项为负）。未消费不计入利润。每个有积分池的渠道（含 A 下 B、C、C 下 B）各自算；C 把积分卖给下属 B 后，那部分在 B 的池里，不再算 C 的未消费。

## 6. 冲正

不得删原流水。所有相关账户成对补记并可溯源：用户充值积分 / 赠送积分 / 佣金钱包；渠道充值、已消费/未消费、营销冻结与已发放；供应商支出。冻结中的在冻结档回冲，已发放的在已发放档回冲。每条含原分录 ID、原因、操作人、时间；同一幂等键只成功一次。

## 7. 本仓库落地状态

检查日期：2026-09-09。

已落地：渠道父子约束（A 建 B/C，B 无下属，C 只建 B）；C 管理员只能在本组织下建 B；C 下 B 自有积分池，C 可通过 `/channel/quotas/grant` 向其划拨；分佣/达线仍按 C 覆盖其下属 B。注册预发推广码；用户 `can_commission`；计佣两跳 `direct`/`indirect`；无资格或无推广角色不计佣；佣金计提写入渠道营销冻结流水，解冻转到已发放并入账用户佣金钱包（不抵 API）；用户钱包区分赠送积分与充值积分，消费顺序为赠送 → 充值，赠送不可退；达线规则（累计消费 / 单笔充值）可配，A/B 走平台、C 可覆盖，达标自动赋 `can_commission`；供应商/向上游付款线下支出只记账（金额为负；必填金额、来源类型、幂等键；`channel_org_id` 由系统按操作者账本写入；冲正成对补记）；渠道盈亏汇总 API；C 渠道台可改本池分佣比例；无分佣资格的分享在被推荐人注册时发赠送积分并记营销已发放。渠道台 `/channel/ledger`、`/channel/rules` 与管理台账本/达线页面对应这些接口。

## 8. 人工佣金打款与退款核对（2026-09-18）

- 线上登记仅记录已经完成的线下打款，不调用银行或支付商转账。新登记在同一事务中保存凭证、扣减原收款人佣金钱包、记录 `commission_payout` 出账和更新结算状态；原佣金未入账或余额不符时拒绝登记。同一结算单及凭证重试只执行一次。
- 未打款佣金退款时冲回原佣金钱包；已经打款的佣金退款时不再扣钱包，也不扣 API 积分或自动抵扣后来获得的佣金。账务模块另记 `billing_commission_recoveries` 待核对金额，关联原佣金、入账流水、出账流水和结算单。用户钱包与结算单显示待财务核对提示。
- 待核对记录不表示资金已经追回。财务或平台管理员可在佣金页面登记线下已经实际收回的款项，支持部分收回。每笔保存金额、凭证、内部备注、操作人和时间；收款记录、累计已收回金额、审计及审计事件在同一事务提交。相同操作重试不会重复登记，重复凭证、超额登记和结清后新增登记均拒绝。全部收回后标记结清，历史凭证保留。本版本不提供自动转账、自动追回、自动抵扣或豁免。历史人工打款单不自动补扣钱包，上线前须单独核对历史余额与付款证据。
- 财务/平台管理员可读写追回记录，审计只读；其他后台角色无权访问全量记录。用户只能在钱包查看自己的金额、结清状态及收款凭证，不展示内部备注或财务操作人。钱包待收回金额仅汇总未收回部分，结算单和推广者后台同步显示部分收回/已结清状态。
- 封禁/解封的用户状态与相关佣金状态在同一事务提交；佣金入账失败时用户状态一并回滚。收款角色查询共用账务事务连接，读取失败不会静默跳过入账。


## 9. 历史佣金核对与计算快照（2026-09-21）

- 新计提保存原分佣策略快照及原收款角色，和消费账务共用事务；读取归因、资格或策略失败时整体失败，不静默少计。策略调整创建新版本，不覆盖历史策略；冻结天数允许明确设为 0。
- 重算接受消费请求编号或用量编号，使用消费原批发价和佣金原快照。已经正确的记录保持不变，不重新开始冻结、不重复扣款。没有有效佣金时不根据今天的资格补发，已退款消费不恢复佣金。
- 仅仍处于冻结状态且有完整原快照的计算差额允许自动成对冲正重建；保留原到期时间，原记录与新记录可追溯。修正、营销记账及审计事件同事务；失败整体回滚。
- 历史缺快照，或已经解冻、暂停、结算、打款的差额，必须人工核对资金凭证，不从当前配置猜测历史应付金额。本次迁移不伪造旧快照或自动补扣历史余额。

### 管理员交接

新建 C 下的 B 继承 C 品牌，模型授权初始为空。平台只给官方直属 B/C 授权；C 只能从自己已授权且已上架的模型中授权给直属 B，并可撤销。渠道可自行下架本渠道模型，下架向其下属生效；自行上架不能越过上级撤权。平台模型全局下架立即使所有渠道不可用。已有渠道不自动改品牌或授权，须先核对实际经营归属。

平台管理员在渠道详情的“渠道管理员交接”中操作：接手人先通过该渠道推广链接注册，再按邮箱授权；必须填写原因并复核对象。目标须为该 B/C 渠道的正常用户，不能叠加其他后台管理角色。授权不更改注册归属，不创建或代管密码，不授予平台权限。可在同一入口撤销，个人账户和历史账务保留；权限与审计同事务，重复请求不会重复授权。上线交付前必须核验接手人实际登录后能看到正确渠道，撤销后现有会话不再有管理访问。


## 10. OEM 管理台导航（2026-09-30）

OEM 沿用平台菜单分组、名称、顺序和图标；仅删除「目录与网关」组和「OEM 品牌」入口。其管理范围为自身品牌与直属 B，不能创建下级 C，也没有提供商、路由、全局告警阈值、熔断、备份等技术操作权限。B 继续保留独立且有限的后台。

- 账务：套餐审核、支付、余额/充值、用量/账单、成本/毛利。
- 分销：渠道租户、推广码、佣金策略。自身模型授权及下属模型授权归渠道租户；归因归推广码；佣金规则、明细、结算归佣金策略。
- 运营：指标、对账、媒体任务、用户/项目、告警、应急手册、审计日志、系统设置。用户 API Key 归用户/项目；自身品牌、语言外观与个人两步验证归系统设置。

新指标、媒体与审计接口从服务端确认 OEM 身份及直属关系。传入无权渠道直接拒绝；媒体只返回任务状态元信息；审计只返回操作人、对象和时间，不返回可能含密钥的前后快照。成本/毛利展示已确认调用的客户收入与平台批发成本差额，未扣佣金或经营费用；不改变网关结算，也不暴露平台供应商报价。业务告警提示待对账和近 24 小时失败媒体任务，应急手册指引业务处置与技术支持联系。
